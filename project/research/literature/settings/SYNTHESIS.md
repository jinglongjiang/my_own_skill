# 可见响应类型与不完整观测：已核查边界

检查日期：2026-10-14。冻结问题见上级 QUESTION_FREEZE.md。本次仅公开网页只读研究，未运行作者代码；所有数值都是原论文报告，不是本仓库实测。

## 结论

1. **最贴近隐藏响应类型的是 HEIGHT。** 已发表 T-ASE 全文 Sec. V-A 使用响应/不响应机器人的混合 ORCA 人群；作者代码在生成每个动态人时抽取一次 `react_to_robot`，机器人观测不含该位。这超过“只隐藏目标”的设定，但不是“所有人都能观察并响应机器人”，也没有显式类型后验估计。详见 [全文笔记](papers/HEIGHT.md) 和 [原文](https://arxiv.org/html/2411.12150v4)。
2. **几何遮挡优先读 PaS。** Sec. III/IV 明确射线遮挡推断，且同时有 3m 传感半径；仿真人不回应机器人。不能用它支持双向人机交互。[笔记](papers/PaS.md)，[原文](https://arxiv.org/pdf/2210.00552)。
3. **角度 FoV 优先读 DS-RNN。** Sec. IV-A/B 分别测角度 FoV 与高人数 Group 场景，不能把两轴拼成联合实验；没有核实几何遮挡。[笔记](papers/DSRNN.md)，[原文](https://arxiv.org/pdf/2011.04820)。
4. **标题容易误导的近邻：MapMultiPolicy。** Sec. V-B2 明确不在同一环境混 ORCA/SFM；它是跨环境多策略训练，不是所求混合隐藏个体类型。[笔记](papers/MapMultiPolicy.md)，[原文](https://arxiv.org/pdf/2109.02541)。

## 统计与复现警告

- 四篇均未在选取的主导航结果报告独立训练 seed 数和置信区间。只转录原始点数，不补造区间或显著性。需要原始逐回合配对结果才能按本仓库标准复算。
- HEIGHT 在测试集上从最后五个 checkpoint 中选最好，存在选择乐观性；Table II/III 的部分 full-model 数字不同，笔记保留来源，不合并。
- HEIGHT 当前 main 的人数口径、观测噪声开关与论文文字存在待核对差异；动作单位亦需固定版本核查。场地边界经代码复核与12m描述相容。README 提示渲染同步 bug。公开代码≠论文结果已复现。
- PaS Table I 的 timeout 处理按其 caption 原样保留。DS-RNN 导航时间只按成功回合计算，不是全任务平均代价。
- 没有把这些点数同 KDA s443、80动作、2100根状态的事后回报表对比。

## 能支撑什么，不能支撑什么

【推论】“部分人会回应机器人且响应类型不显式提供”及“角度/距离/遮挡导致观测不完整”都已有明确已发表近邻，不能仅靠换这类设定主张方法贡献。现有证据不回答本仓库动作级事后标签可学性，也不证明任何新方法有效。

两种可行的文献使用方式：
- 用 HEIGHT 对照交互假设，用 PaS/DS-RNN 分别对照遮挡与 FoV，保持三种困难可区分。
- 若要同时引入交互和遮挡，可把 HEIGHT 当组合设定近邻，但先冻结作者版本和观测协议，不能直接采用 current-main 默认声称复现论文。

推荐第一种：设定证据较清楚，较容易看出差异来自响应、缺失观测还是方法本身。本次仅建议如何界定相关工作，不要求开展新的实验。
