# 使用者档案（可改）

技能读取这份文件来决定默认行为。换项目或换人时改这里，不用改技能正文。

- **回复语言**：中文。
- **目标产出**：方法论文。评测型、诊断型结论只作为方法的动机和证据，不作为主贡献。
- **研究风格**：对标与临摹优先——找一篇已有工作，解决它遗留的问题，在同一问题上做得更好。有先行研究是优势，不是障碍。
- **最稀缺资源**：时间。任何建议都要给出成本（GPU 小时、墙钟、往返次数）。
- **算力**：远程单卡 GPU 做训练和大规模评测；本地机器做编辑、静态检查、smoke 和短时调试。长任务先 smoke 再正式运行，启动后要有检查点，不挂着不管。
- **分工**：分析与协议由 Claude 写；大规模执行交给另一个编码代理（如 Codex）；第三方模型（如 GPT）的评审意见逐条核对后再采纳。
- **文件纪律**：没有明确要求时只读不写；临时产物放临时目录；不动别的任务的目录和进程；不做破坏性 git 操作。
- **进程检测**：不用会把查询命令自身算进去的写法（`pgrep -f <pattern>`、`ps | grep -c`）。用 PID 文件、完成标记文件或输出文件数量。
