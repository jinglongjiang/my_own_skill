# 尺子回测

目的：在用尺子淘汰新候选之前，确认它的读数和闭环结局对得上。

## 步骤
1. 从 `RECORD.md` 里各取至少一个：
   - **阴性**：闭环里确认净零或变差的候选
   - **阳性**：闭环里确认有效的改动
2. 只用该候选当时已有的材料，把它写成规则函数（rule 模式）或在同一批状态上生成新打分（compare 模式）。
3. 运行尺子，记录读数：检出改善 / 未检出 / 检出变差，以及是否胜过带内随机。
4. 对照闭环结局填表：

| 候选 | 闭环结局 | 尺子读数 | 一致？ | 如不一致，可能的原因 |
|---|---|---|---|---|

## 怎么判
- 阴性和阳性都一致 → 尺子在这类候选上可以用来淘汰。
- 阴性一致、阳性看不见 → 尺子不够敏感，只能用来提示，不能淘汰。常见原因：样本太少、单步口径看不到多步收益、回报表来自另一份权重。
- 阴性不一致（闭环无效但尺子说有改善）→ 单步改善没有转化为闭环收益，记下这一点：以后尺子的"有利"读数不能直接当作闭环预测。

## 示例（随项目附带的阴性回测）
`assets/example_rule.py`（项目根目录 `examples/rules/` 下有同一份）：在并列集合里改选净距最大的候选。该规则在闭环 n=200 配对评测中三个变体全部净零（p = 0.53 / 0.86 / 0.63）。用尺子在 200 个状态的反事实表上查：改变了 26%–43% 的决策，regret 未下降，且与带内随机不可区分。读数与闭环结局一致，用时几秒。
限制：这次回测的表来自另一份骨干权重，每组 66–68 个状态，且没有配套的阳性回测。
