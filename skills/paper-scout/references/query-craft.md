# 检索式写法

## 同问题检索
- 用本领域的原词：任务名、环境名、方法族名。
- 一条检索式 3–6 个词。词太多时 arXiv 后端按"全部包含"匹配，会一篇都找不到。
- 换说法：同义词（crowd navigation / social navigation / human-aware navigation）、上位词、具体方法名、评测环境名。
- 连续两条检索式新增少于 2 篇时，这个问题基本搜完了。
- 用最接近的那几篇的引用和被引再扩一轮（OpenAlex 能给被引数，用网页检索查"cited by"）。

## 跨领域检索：抽象阶梯
把困难一级一级去掉领域名词，直到另一个领域的人能看懂：
1. 原始表述：价值网络在 20 人场景里对前五名候选动作的排序不可靠。
2. 去掉任务：学到的打分函数能选出好的候选集合，但集合内部的次序接近随机。
3. 去掉方法：只有标量回归监督时，头部候选的细粒度次序学不出来；而训练时可以拿到每个候选的精确事后结果。
4. 结构描述词：top-k 内重排序、带特权信息的排序学习、反事实标签蒸馏、回归目标与决策目标不一致。

第 3、4 级是检索用的。停在第 2 级通常太贴近原领域，搜到的还是自己人。

## 选哪些子领域
问"哪个领域把这个结构当成核心问题"：
- 头部次序不准 → 信息检索（重排序）、推荐系统、神经结构搜索的性能预测器
- 训练时有、部署时没有的信息 → 特权信息学习、教师—学生蒸馏、非对称 actor-critic
- 回归目标和决策目标不一致 → decision-focused learning、value-aware 模型学习、预测后优化
- 候选很多、差别很小 → action-gap、对决式 bandit、偏好学习
至少跨三个，每条检索式用 `--probe` 标明。

## 借用之前的自测
四条都成立才算真的跨领域借用，否则只是换了个说法：来源设定确实不同；借来的是具体机制，不是一个引用或通用工具；能说出为什么两边结构相同；适配时利用了这个结构。
